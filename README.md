# ServerLab AI — Competition Edition 2.2

**Сайт авторы: Ақшабаева Сымбат.**

## Жобаның функциялары
- 12 оқу модулі және 36 кеңейтілген сабақ: сервер архитектурасы, CPU/RAM, сақтау және RAID, желілер, виртуализация, қауіпсіздік, мониторинг, дата-орталық, сервер ОЖ және әкімшілеу, веб/деректер базасы/API, жоғары қолжетімділік пен масштабтау, практикалық диагностика.
- Әр сабақта анықтама, түсіндірме, мысалдар, техникалық талдау, практикалық зертхана, жиі кездесетін қате және 3 сұрақтық тест бар.
- Әр сабақта дәл сол тақырып бойынша YouTube ресурсына сілтеме; бірқатар модульде ендірілген бейне. Видеоны конкурс алдында мазмұн мен сапа жағынан тексеріңіз.
- Әр тесттен кейін мотивациялық хабарлама және келесі сабаққа өту.
- Тілді таңдау: қазақша (KZ), орысша (RU), ағылшынша (EN). Аударма Google Translate арқылы болғандықтан интернет қажет және техникалық терминдерді тексеру керек.
- Сервер конфигурациясы зертханасы: жұмыс түріне, пайдаланушы санына, сақтауға және қолжетімділік талабына қарай бастапқы ұсыныс береді. Бұл оқу симуляторы, кәсіби сыйымдылық жоспарын алмастырмайды.
- Жеке кабинет, прогресс, тест тарихы, XP, мини-ойындар және ИИ көмекшісі (API-сыз демонстрациялық жауаптар да бар).
- Қорғалған әкімші панелі: топ/сынып бойынша аналитика, әр оқушының барлық 36 сабаққа арналған мәртебесі, ең жақсы тест ұпайы, әрекеттер саны және CSV экспорты. Әкімші рөлі тек сервердегі `ADMIN_EMAIL`/`ADMIN_PASSWORD` арқылы орнатылады.

## Демо және толық режим
- Егер PostgreSQL қосылмаған болса, кіру бетіндегі **«Демо режимде көру — аккаунтсыз»** батырмасын басыңыз. Прогресс осы браузерде сақталады; ол ортақ тізімге қосылмайды.
- Ортақ оқушы тіркелгісі және әкімші панелі үшін PostgreSQL қажет: `DATABASE_URL`, `ADMIN_EMAIL`, `ADMIN_PASSWORD` (кемі 12 таңба), `ADMIN_NAME`. Құпия параметрлерді GitHub-қа жүктемеңіз; Render Environment параметрлерінде сақтаңыз.
- OpenAI-ге негізделген генеративті жауаптарды қосу үшін `OPENAI_API_KEY` және қажет болса `OPENAI_MODEL` сервердегі Environment-та беріледі. Кілт ешқашан браузер кодында сақталмайды.

## GitHub/Render арқылы жаңарту
1. Осы архивті ашып, `serverlab_ai` папкасына кіріңіз.
2. Бар GitHub `serverlab-ai` репозиторийін ашыңыз → **Add file → Upload files**.
3. `serverlab_ai` ішіндегі барлық файлды репозиторий түбіріне апарыңыз; аттас файлдарды алмастырыңыз, жаңа файлдарды қосыңыз; `Commit changes` басыңыз.
4. Render Web Service → Settings: Build Command=`npm install`, Start Command=`npm start`.
5. Render Environment-та `DATABASE_URL`, `ADMIN_EMAIL`, `ADMIN_PASSWORD`, `ADMIN_NAME`; нақты генеративті ИИ қажет болса `OPENAI_API_KEY` орнатыңыз.
6. Жаңа файлдар committed болса, Render deploy басталуы керек. Сайтта демо режимін немесе тіркелген аккаунтты сынаңыз.

## Жергілікті іске қосу
```powershell
npm install
npm run check
npm start
```
Одан кейін браузерде `http://127.0.0.1:4173` ашыңыз. Node.js 20+ керек. PostgreSQL-сыз демо режимі қолданылады; ортақ аккаунттар үшін `DATABASE_URL` керек.

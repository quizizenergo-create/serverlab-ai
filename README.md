# ServerLab AI — оқу платформасының прототипі

ServerLab AI — «Білім берудегі жасанды интеллект» конкурсына арналған цифрлық оқу платформасының прототипі. Пәні: **«Серверлік техникалық құралдар»**.

## Не бар?

- 8 оқу модулі және 24 параграф;
- әр параграфқа теория, қарапайым анықтама, практикалық мысалдар және 3 сұрақтық тест;
- тест нәтижесіне қарай сабақ прогресін белгілеу және XP ұпайларын жинау;
- жеке кабинет: оқушы аты, топ, оқу мақсаты;
- оқу аналитикасы, жетістіктер, соңғы әрекеттер және JSON есепті жүктеу;
- ИИ-тәлімгер: қарапайым тілмен түсіндіру, мысал келтіру, курс прогресіне сүйеніп ұсыныс беру;
- үш мини-ойын: терминді сәйкестендіру, флеш-карталар, жылдам тест;
- конкурс критерийлеріне сәйкес «Жоба туралы» бөлімі: педагогикалық мәселе, мақсатты топ, ИИ қолдану тәсілдері, практикалық маңыз, басқа оқу орындарына бейімдеу, академиялық адалдық және дербес деректерді қорғау;
- қараңғы режим және мобильді экранға бейімделетін интерфейс.

## Іске қосу: ең қарапайым жол

1. ZIP архивті аш.
2. `index.html` файлын екі рет басып, браузерде аш.
3. «Профиль баптауы» арқылы атың мен тобыңды енгіз.

Бұл режимде негізгі оқу материалы, тесттер, ұпайлар және ойындар браузер ішінде жұмыс істейді. ИИ-чат оқу базасына сүйенген демо жауаптарды қолданады.

## ИИ API-мен іске қосу (міндетті емес)

Нақты генеративті ИИ қолдану үшін Node.js 18 немесе одан жаңа нұсқа қажет. API кілтін браузерге немесе `app.js` файлына жазба — ол тек серверде сақталуы керек.

**Windows PowerShell:**

```powershell
cd path\to\serverlab_ai
$env:OPENAI_API_KEY="СЕНІҢ_API_КІЛТІҢ"
$env:OPENAI_MODEL="gpt-5-mini"
node server.js
```

Содан кейін браузерде `http://127.0.0.1:4173` адресін аш. API кілті орнатылмаса да сервер демо режимінде қосылады. Нақты модельді қолдану үшін жеке API қолжетімділігі мен есеп айырысу параметрлері қажет болуы мүмкін.

**Ескерту:** бұл — бір компьютерде таныстыруға арналған прототип. Прогресс `localStorage` ішінде сақталады, сондықтан ол басқа компьютерге автоматты түрде көшпейді және бұл нағыз көппайдаланушылық жүйе емес. Колледжге нақты енгізу үшін дерекқор, қауіпсіз аутентификация, серверлік профильдер, HTTPS, рөлдер, резервтік көшіру, құпиялылық саясаты және оқытушы панелі қажет.

## Конкурста көрсетуге болатын демонстрация

1. Жеке профиль жасап, курс бетін аш.
2. Бір параграфты оқы, тест тапсыр және XP ұпайының өскенін көрсет.
3. «ИИ-тәлімгер» бөлімінде RAM мен SSD айырмашылығын түсіндіруді сұра.
4. Мини-ойынмен терминдерді бекіт.
5. «Менің прогресім» бөлімінде аяқталған сабақтарды, тест нәтижесін және жеке ұсынымды көрсет.
6. «Жоба туралы» бөлімінде педагогикалық мәселе, қолданылатын ИИ және этикалық талаптарды қорға.

## Жобаның шектеулері

- Демо режимдегі чат нақты генеративті модель емес — алдын ала әзірленген оқу жауабын таңдайды.
- Нақты генеративті жауап үшін серверді API кілтімен іске қосу керек.
- Тест ұпайлары оқу прототипін көрсетуге арналған; колледждің ресми бағалау жүйесі ретінде қолданылмауы керек.
- Жеке кабинет деректері бұл прототипте тек сол браузерде сақталады.

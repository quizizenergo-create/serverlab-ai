# ServerLab AI — Competition Edition 2.3

**Сайт авторы: Ақшабаева Сымбат.**

## Жобаның мүмкіндіктері
- 12 оқу модулі және 36 кеңейтілген сабақ: сервер архитектурасы, CPU/RAM, сақтау және RAID, желі, виртуализация, қауіпсіздік, мониторинг, дата-орталық, серверлік ОЖ, веб/деректер базасы/API, жоғары қолжетімділік, диагностика.
- Әр сабақта түсіндірме, мысалдар, қосымша практикалық материал және тест бар; аяқталған тесттен соң мотивациялық хабарлама көрсетіледі.
- Әр сабаққа тақырыптық видео іздеу сілтемесі; видеоларды сабақ алдында қарап тексеру керек.
- Білім алушының жеке аккаунты, топ/сынып өрісі, серверде сақталатын оқу прогресі, тест нәтижелері, XP және ойындар.
- Қорғалған әкімші панелі: тіркелген білім алушылар тізімі, тобы/сыныбы бойынша статистика, тест нәтижелері, аяқталған сабақтар және CSV экспорты.
- Қазақша бастапқы интерфейс, KZ/RU/EN тіл ауыстырғышы. Негізгі интерфейс сөздігі офлайн жұмыс істейді; барлық ұзын сабақ мәтіндерін автоматты аудару үшін Render Environment ішінде `OPENAI_API_KEY` болуы керек. Бұл API пайдаланылғанда аударма сұраулары API шығынын тудыруы мүмкін.
- Сервер конфигурациясы зертханасы және ИИ-тәлімгер. API кілті серверде ғана сақталады.

## Маңызды: базаны жұмыс істету
1. Render Dashboard ішінде `New +` → `PostgreSQL` таңда.
2. Базаға `serverlab-ai-db` деген атау бер. Веб-сервис қай аймақта болса, дәл сол аймақты таңда.
3. База жасалғанда оның **Connect** бөлімін ашып, **Internal Database URL** көшір. Құпия URL-ді ешкімге жіберме.
4. Render ішіндегі `serverlab-ai` **Web Service** → **Environment** → `Add Environment Variable`.
5. `DATABASE_URL` айнымалысына көшірілген Internal Database URL мәнін қой.
6. Сол Environment бөлімінде `ADMIN_EMAIL`, `ADMIN_PASSWORD`, `ADMIN_NAME` айнымалыларын орнат:
   - `ADMIN_EMAIL`: әкімші үшін өзің басқаратын email.
   - `ADMIN_PASSWORD`: кемінде 12 таңбалы күшті жеке құпиясөз.
   - `ADMIN_NAME`: `Ақшабаева Сымбат` (немесе әкімші атауы).
   - `OPENAI_API_KEY`: ИИ және толық автоматты аударма керек болса, жеке API кілтін енгіз. Бұл міндетті емес: кілтсіз негізгі интерфейс сөздігі жұмыс істейді, ал ИИ жауаптары демо режимде қалады.
7. `Save, rebuild, and deploy` таңда. Сайт іске қосылған соң `https://...onrender.com/api/status` мекенжайын аш. Дұрыс қосылғанда JSON ішінде `"dbConfigured":true` және `"dbConnected":true` болуы керек.
8. Әкімшіге кіру үшін `ADMIN_EMAIL` мен `ADMIN_PASSWORD` мәндерін сайттың кіру бетіне енгіз. Бұл мәліметтерді GitHub-қа жазба және ешкімге жіберме.

**SSL:** Render сервисі мен PostgreSQL бір аймақта болса, `Internal Database URL` қолдан. `DATABASE_SSL=true` тек сыртқы URL-мен TLS талап етілген жағдайда керек.

**Тегін база туралы:** Render Free PostgreSQL базалары 30 күннен кейін жарамсыз болып қалады. Байқаудан кейін де білім алушылардың деректері сақталуы керек болса, ұзақ мерзімге жарамды сақтау жоспарын таңда немесе деректерді мерзімі біткенге дейін қауіпсіз экспорттап ал. Render шектеулері: https://render.com/docs/free

## Render Web Service баптаулары
- Root Directory: бос, егер `index.html`, `server.js`, `package.json` GitHub репозиторийінің түбірінде болса.
- Build Command: `npm install`
- Start Command: `npm start`
- Node.js: 20 немесе жоғары нұсқа.

## Дерекқордың жұмысын тексеру
- `GET /api/status` — ИИ, аударма және дерекқор қосылымының күйін көрсетеді.
- `GET /healthz` — сервер мен дерекқордың байланысын тексеруге арналған.
- Әкімші панелінде тізім бос болса, алдымен нақты білім алушы аккаунтын жасап, кемінде бір сабақтың тестін аяқта.

## Локалды іске қосу
```powershell
npm install
npm run check
npm start
```
Содан кейін `http://127.0.0.1:4173` мекенжайын аш. Ортақ аккаунттар үшін PostgreSQL `DATABASE_URL` керек.

## Жаңарту GitHub / Render арқылы
1. `serverlab_ai` ішіндегі файлдарды бұрынғы репозиторийдің түбіріне жүктеп, аттас файлдарды алмастыр.
2. `Commit changes` бас.
3. Render жаңа commit-ті автоматты жариялайды. Жарияланбаған болса, `Manual Deploy` → `Deploy latest commit`.
4. `/api/status` арқылы `dbConnected` мәнін тексер; база қосылмаса, Render Logs-ты тексер.

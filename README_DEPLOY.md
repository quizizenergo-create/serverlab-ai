# ServerLab AI — жария сілтемеге шығару

Бұл архив Render сияқты Node.js хостингке орналастыруға бейімделген. `serverlab_ai/server.js` жалпы интерфейске қолжетімді болатындай `0.0.0.0` адресіне тыңдайды, ал портты хостингтің `PORT` айнымалысынан алады.

## GitHub арқылы жариялау
1. GitHub-та жаңа repository жасаңыз.
2. Репозиторийдің негізгі деңгейіне `serverlab_ai` ішіндегі барлық файлдарды жүктеңіз: `index.html`, `styles.css`, `app.js`, `server.js`, `render.yaml`, `README.md`.
3. Render Dashboard ішінде New → Web Service таңдаңыз да, осы репозиторийді қосыңыз.
4. Build Command: `echo "No build step required"`.
5. Start Command: `node server.js`.
6. Free жоспарын таңдаңыз және Deploy жасаңыз.
7. Deploy аяқталғаннан кейін Render берген `https://....onrender.com` сілтемесін ашыңыз.

## ИИ API кілті туралы
Сайтты көрсету үшін API кілті қажет емес: чат демо режимінде болады. Нақты генеративті ИИ қосу керек болса, Render сервисінің Environment бөлімінде `OPENAI_API_KEY` және қажет болса `OPENAI_MODEL` айнымалыларын сервер жағынан орнатыңыз. API кілтін GitHub-қа, `index.html` немесе `app.js` файлына қоспаңыз.

## Ескерту
Бұл оқу прототипі. Оқушы прогресі браузердің `localStorage` қоймасында қалады және басқа құрылғыға автоматты түрде өтпейді. Тегін хостинг бос тұрғанда ұйықтап, келесі ашылуында бір минуттай оянуы мүмкін.

# ServerLab AI 2.2 — обновление для конкурса

**Автор сайта: Ақшабаева Сымбат.** В этом пакете новая версия проекта `serverlab_ai`.

## Что добавлено/исправлено
- 12 модулей / 36 уроков с расширенными объяснениями, примерами, практическими заданиями, частыми ошибками и тестом после каждого урока.
- На каждом уроке есть отдельная видеоссылка по теме; в отдельных основных модулях встроены рекомендованные YouTube-видео. YouTube и автоматический перевод требуют интернет.
- После каждого теста появляется мотивационное окно с результатом и кнопкой перехода дальше.
- Языковые кнопки KZ / RU / EN видны на экране входа и внутри приложения.
- Новая «Сервер зертханасы»: практический тренажёр для выбора CPU/RAM/storage/network с пояснениями и оговоркой, что конфигурация — учебная оценка.
- У исправления рекомендации убран некорректный вывод `${allLessons.length}` как обычного текста.
- Вход без аккаунта «Демо режимде көру — аккаунтсыз» позволяет посмотреть сайт без PostgreSQL; прогресс хранится только в этом браузере.
- Администратор видит группы/классы, сводные результаты и разворачиваемый отчёт по каждому ученику на 36 тем: статус, лучшая оценка и количество попыток. CSV экспорт остаётся.
- Авторство Ақшабаева Сымбат указано на экране входа, в подвале и на странице «Жоба туралы».

## Обновление старого сайта
1. Скачайте этот ZIP и распакуйте.
2. Откройте папку `serverlab_ai`.
3. На GitHub откройте свой прежний репозиторий `serverlab-ai`.
4. Выберите **Add file → Upload files** и загрузите **содержимое папки `serverlab_ai`**, а не сам ZIP. Атласные файлы замените, новые добавьте.
5. Нажмите **Commit changes** — Render должен автоматически развернуть обновление.
6. В Render проверьте Build Command: `npm install`, Start Command: `npm start`.

## Демо и полная версия
- Без базы данных нажмите на экране входа **Демо режимде көру — аккаунтсыз**. Это позволяет показать курс, тесты, видео ресурсы, игры, мотивационное окно и тренажёр; прогресс остаётся локальным.
- Для реальных регистраций, общей базы и админ-панели нужно подключить PostgreSQL и настроить в Render Environment: `DATABASE_URL`, `ADMIN_EMAIL`, `ADMIN_PASSWORD` (не короче 12 символов), `ADMIN_NAME`. Не загружайте секреты в публичный GitHub.
- Генеративный ИИ включается серверным ключом `OPENAI_API_KEY`; без него используется демонстрационная учебная база. Ключ не помещать в HTML/JS и GitHub.

## Локальная проверка (Windows PowerShell)
Откройте терминал в папке `serverlab_ai`:
```powershell
npm install
npm run check
npm start
```
Откройте `http://127.0.0.1:4173`. `npm run check` проверяет синтаксис JavaScript.

## Честные ограничения
- Интерфейс переводится через Google Translate, поэтому нужен интернет, а машинный перевод технических терминов стоит проверить.
- В отдельных главных разделах встроены YouTube-видео; у каждого урока в любом случае есть тематическая ссылка для поиска видеоматериала. До защиты проекта проверьте доступность и соответствие роликов.
- Серверный список учеников и общие результаты не работают без PostgreSQL. Демо-режим не показывает администратору общие регистрации и не должен выдаваться за настоящий мультиаккаунтный режим.
- Рекомендации симулятора конфигурации являются учебными примерами, не готовой инженерной спецификацией.
